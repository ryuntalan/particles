Today, I built an AI research agent in 10 minutes. 

I used a tool called n8n, an open-source platform for automating workflows. It’s often used for things like sending reports or syncing apps, but with built-in support for large language models (LLMs), it’s also great for prototyping AI tools.



![n8n research workflow](images/n8n/n8n-3.png)

To make it work, I connected two key pieces:
* **OpenRouter**, a unified API for LLMs. It gives access to models like GPT-4, Claude, and Mistral—all through a single key.
* **Perplexity**, a research-focused AI that pulls real-time information from the web and delivers fast, citation-backed answers.

Once connected in n8n, I added a basic chat interface and asked the agent for a marathon training plan. In seconds, it returned a detailed, week-by-week schedule with mileage, cross-training, and recovery days.

![chat interface and marathon plan](images/n8n/n8n-4.png)

If you want to learn more about building with n8n, check out [Nate Herk’s YouTube channel](https://www.youtube.com/@nateherk).

### What this means for Design

Tools like n8n can help designers explore ideas faster and stay more informed. You can set up workflows to track trends, summarize articles, or organize user feedback. It’s a way to reduce busywork and make space for thinking, learning, and creating.
